# MyAbility Path (ГРАДители · достъпен град)

Едно Django приложение, което прави всичко: екран за Гошо, панел за MAP, API и анализ на отклоненията.
Без външни услуги и API ключове (картата е Leaflet + OpenStreetMap).

## Стартиране

```bash
python -m venv venv && source venv/bin/activate      # на Windows: venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py simulate --reset                    # демо данни
python manage.py createsuperuser                     # по желание, за /admin/
python manage.py runserver 0.0.0.0:8000
```

- `http://localhost:8000/`      - екранът на Гошо (карта, "Докладвай проблем", "Потвърждавам", въпросник)
- `http://localhost:8000/map/`  - панелът на MAP (карта + списък по приоритет)
- `http://localhost:8000/admin/` - всички данни


## Демо (най-бързо)

Отвори `http://localhost:8000/` на лаптоп: телефонът на Гошо е вляво, панелът на MAP вдясно (на екран под 1180 px панелът се скрива; на телефон приложението е на цял екран).

- **🎬 Авто демо** - целият сценарий с един клик (~35-60 сек според маршрутната услуга):
  1. нормален ден, маршрутът съвпада;
  2. 🚧 се появява по средата на улицата;
  3. Гошо #1 заобикаля -> отклонение -> въпросник (описва проблема);
  4. Гошо #2 (пропуска въпросника) и #3 (отговаря) -> проблемът става **активен**;
  5. Гошо #4 вижда активния проблем и потвърждава "Още е там";
  6. резултатът отива в панела на MAP.
  Повторното натискане спира демото. Преди представянето: "Изчисти данните" в панела (само при DEBUG).
- **📍 Маршрут** - докосни "вкъщи", после "работа".
- **🚧 Препятствие** - докосни улицата (залепва се към маршрута). Докосни 🚧, за да го махнеш.
- **▶ Тръгни** - Гошо върви (по заобикалянето, ако има 🚧). **👤 Нов Гошо** - друг потребител.
- **⚠️ Докладвай** и попъпът на активен проблем ("Още е там" / "Няма го") покриват другите два клона на Гошо.

## Как работи

Защо старото сравнение винаги казваше "съвпада": краищата A и B на една минута са върху реалния път
на Гошо, така че най-краткият маршрут A->B е точно неговият път. Заобикалянето се вижда само в по-дълъг
прозорец, който съдържа и излизането от улицата, и връщането (виж `test_old_method_misses_detour`).

1. **Минута** - телефонът праща точките от последния checkpoint (~`WALK_METERS_PER_MINUTE` м) към `/api/segment/`.
2. **Плъзгащ прозорец** - сървърът слепва последните `WINDOW_MINUTES` (8) минути: A = checkpoint преди 8 мин, B = сега, и пита маршрутната услуга за A->B.
3. **Сравнение** (`compare_paths`) - отклонение е, ако поне `OFF_ROUTE_MIN_M` (30 м) са извън коридора `ON_ROUTE_METERS` (25 м) **и** Гошо е вървял поне `DETOUR_MIN_EXTRA_M` (25 м) повече. Втората проверка отсява равностойни алтернативи и GPS шум.
4. **Потвърждение** - първото различие е само "подозрение". Записваме, когато допълнителните метри спрат да растат (върнал се е на маршрута), в края на пътуването или ако подозрението продължи твърде дълго.
5. **Две точки** - checkpoint-ът, където е излязъл от маршрута, и средата на пропуснатата част (оценка къде е препятствието; по нея групираме).
6. **MAP анализ** - отклонения до `MERGE_METERS` се сливат; проблемът е *активен* при `MIN_USERS` различни хора. Въпросникът дава тип и ниво (или "няма информация"). Приоритет = сигурност × тежест, сигурност = хора + потвърждения - отричания.

Фейк препятствието (`city/detour.py`): ORS `avoid_polygons` -> междинна точка встрани (OSM/Google) -> схематично заобикаляне без мрежа. В журнала на телефона пише кой метод е използван.

### Маршрутна услуга

Настройва се в `.env` (зарежда се автоматично) или чрез променливи на средата:

```
ROUTING_PROVIDER=ors          # ors | osm | google | mock
ORS_API_KEY=...
ORS_PROFILE=foot-walking      # или wheelchair
```

Ако услугата не отговори, приложението пада на права линия и пише предупреждение. Безплатният ORS има лимит ~40 заявки/мин; повтарящите се заявки се кешират.

Демо маршрутът е в `config/settings.py` (`DEMO_START`, `DEMO_END`: от The Steps до Градската градина). Препятствието се слага по средата на предложения маршрут.

## Тестове

```bash
python manage.py test city     # синтетична улична мрежа, без интернет
```

## Демо данни

```bash
python manage.py simulate --reset   # без интернет: 10 потребители, 6 от тях се отклонили на едно място
python manage.py analyse            # преизчислява проблемите от отклоненията
```

Всички настройки са най-долу в `config/settings.py`.

## Идеи за следващи стъпки

- `ORS_PROFILE=wheelchair` вместо `foot-walking` - по-реалистичен "препоръчан" маршрут за количка
- Малки заобикаляния (пресичане на улицата заради липсващ скосен бордюр) остават под коридора от 25 м; за тях трябва по-точен GPS или по-тесен коридор
- Истинско GPS следене от мобилно приложение (сега е фейк: Гошо се движи по маршрута)
- Автентикация за панела `/map/` и CSRF токени за API-то (сега е изключено за по-лесен хакатон)
- Поверителност: анонимни id, изтриване на старите пингове (`Ping`)
- PostGIS, ако данните станат много
